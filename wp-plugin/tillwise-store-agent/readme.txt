Safe, stateful WooCommerce store operations exposed through WordPress Abilities for MCP agents.

== Description ==

Tillwise Store Agent registers WooCommerce management abilities for daily briefings, low stock checks, guarded price previews, safe apply, persistent history, undo, and guardrails.

== Installation ==

Copy this directory to wp-content/plugins/tillwise-store-agent and activate it after WooCommerce.
